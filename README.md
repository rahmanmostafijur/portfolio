# Portfolio

My personal site: who I am, what I build, and how to reach me.

**Live:** https://mostafij.vercel.app

## Built with

React, TypeScript, Vite and Tailwind CSS, deployed on Vercel. Multi-page site with a downloadable resume, project write-ups and contact links.

## Running locally

**Install:** npm install

**Dev server:** npm run dev (http://localhost:5173)

**Production build:** npm run build, then npm run preview

## Structure

**src/** components, pages and styles

**public/** static assets and resume PDF
